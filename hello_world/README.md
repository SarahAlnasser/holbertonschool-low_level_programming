# C - Hello, World

First steps in C: the four stages of compilation (preprocessor, compiler, assembler, linker), gcc, and printing with puts and printf.

## Files
| File | Description |
|------|-------------|
| 0-preprocessor | Runs the C file in $CFILE through the preprocessor and saves the result in `c` |
| 1-compiler | Compiles the C file in $CFILE into an object file without linking |
| 2-assembler | Generates the assembly code of the C file in $CFILE into a .s file |
| 3-name | Compiles and links the C file in $CFILE into an executable named cisfun |
| 4-puts.c | Prints a quote using puts |
| 5-printf.c | Prints a sentence using printf |
| 6-size.c | Prints the size of various C types |
